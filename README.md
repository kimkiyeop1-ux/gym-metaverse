# 가상 체육관 (gym-metaverse)

학교 체육관을 3D로 재현한 웹 공간입니다. 기획은 [PLAN.md](PLAN.md)를 참고하세요.

## 실행
빌드 과정이 없습니다. 라이브러리(Three.js, cannon-es)는 `js/vendor/`에 포함되어 있습니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속 (주소 뒤에 ?fps 를 붙이면 FPS 표시)
```

## 접속 주소
https://kimkiyeop1-ux.github.io/gym-metaverse/  (주소 뒤에 `?fps` 를 붙이면 화면 속도 표시)

## 설정
학교명 등은 `js/config.js` 한 곳에서 바꿉니다. 화면 제목, 무대 현수막, 홈 화면 앱 이름에 모두 반영됩니다.
- `schoolName`: 학교 이름
- `equipment.ballScale`: 공 크기 비율 (1 = 실제 규격)
- `equipment.volleyNetHeight`: 배구 네트 높이

## 여러 명 동시 접속
- 입장할 때 **닉네임**(2~8글자)과 **방 코드**(예: `1-3`, 비우면 `공용`)를 넣습니다. 같은 방 코드끼리만 만납니다. 방마다 최대 30명.
- 공·기구는 함께 씁니다. 마지막으로 만진(잡기·차기·밀기) 사람의 기기가 계산해서 다른 사람에게 보냅니다.
- 친구끼리 플래그를 뽑을 수 있고, 골은 모두에게 "○○ 골!"로 알려집니다. 연습 친구는 방장(가장 먼저 들어온 사람) 화면에서 움직입니다.
- 서버: Firebase 실시간 데이터베이스 + 익명 로그인. `js/config.js` 의 `firebase` 에 설정값을 넣고, `database.rules.json` 내용을 Firebase 콘솔의 Realtime Database → 규칙에 붙여 넣습니다.
- 설정이 없으면 혼자 하기만 됩니다. 개발 중에는 주소 뒤에 `?net=local` 을 붙이면 같은 브라우저의 여러 탭끼리 테스트할 수 있습니다.
- 채팅은 없습니다. 닉네임은 기본적인 나쁜 말을 막습니다.

## 홈 화면에 추가
- 안드로이드(크롬): 시작 화면의 **📲 홈 화면에 추가** 버튼
- 아이폰(사파리): 공유 버튼(□↑) → "홈 화면에 추가"
- 한 번 열었던 기기는 인터넷이 없어도 다시 열 수 있습니다.

## 효과음
소리 파일 없이 브라우저가 직접 만듭니다(`js/sound.js`). 오른쪽 위 🔊/🔇 버튼으로 켜고 끕니다.

## 조작
- PC: WASD/방향키 이동, 스페이스 점프, 마우스 드래그 시점, 휠 확대·축소
- 모바일: 왼쪽 조이스틱 이동, 오른쪽 드래그 시점, 두 손가락 확대·축소, 점프 버튼
- 기구 동작 (PC 키 / 모바일은 기구 가까이 가면 버튼이 나타남)
  - E: 잡기·놓기·플래그 착용·플래그 뽑기
  - Q: 꾹 눌러 힘 모아 던지기 (농구공을 들고 골대를 보면 '슛', 초록 구간에서 떼면 골)
  - F: 차기·라켓 치기·스파이크·킨볼 띄우기
  - R: 토스 (배구공·빅발리볼)
  - 줄넘기: 들고 F(또는 점프)로 시작, 줄이 발밑에 올 때 맞춰 뛰기
  - 훌라후프: F 돌리기(계속 눌러 힘 주기), Q 바닥에 굴리기
  - 추크볼 골대·배드민턴 지주: 몸으로 밀어서 이동
  - 🧺 정리: 모든 공과 기구를 제자리로

## 용기구 보관 구역
모든 공·작은 용기구는 −z 벽 쪽 **용기구 보관 구역**의 이름표가 붙은 칸에 놓여 있고, 🧺 정리 버튼을 누르면 각자 칸으로 돌아갑니다.
칸 순서·위치·이름은 `js/storageArea.js`의 `STORAGE_SLOTS`에서 바꿉니다.

## 저장 규칙
localStorage 키는 모두 `gym_`으로 시작하며(`js/storage.js`), 다른 키는 읽거나 지우지 않습니다.

## 업데이트 배포 시
`index.html`의 `VERSION` 값을 바꾸면 휴대폰 브라우저와 홈 화면 앱이 예전 파일(캐시) 대신 새 파일을 받습니다.
(서비스 워커 `sw.js` 가 새 버전을 설치하고 예전 저장본을 지웁니다. 저장본 이름은 `gym-metaverse-` 로 시작하며 다른 이름의 저장본은 건드리지 않습니다.)
`js/`에 새 파일을 추가하면 같은 곳의 `MODULES` 목록에도 이름을 넣어야 합니다.
