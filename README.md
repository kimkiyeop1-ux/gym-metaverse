# 가상 체육관 (gym-metaverse)

학교 체육관을 3D로 재현한 웹 공간입니다. 기획은 [PLAN.md](PLAN.md)를 참고하세요.

## 실행
빌드 과정이 없습니다. 라이브러리(Three.js, cannon-es)는 `js/vendor/`에 포함되어 있습니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속 (주소 뒤에 ?fps 를 붙이면 FPS 표시)
```

## 🏫 내 학교용으로 만들기 (사본 만들기)
누구나 이 저장소의 사본을 만들어 자기 학교에 맞게 고쳐 쓸 수 있습니다. 컴퓨터에 아무것도 설치하지 않고 **GitHub 웹사이트에서만** 할 수 있어요.

**1. 사본 만들기**
1. GitHub에 가입·로그인합니다.
2. 이 저장소 페이지 오른쪽 위의 초록색 **Use this template → Create a new repository** (또는 **Fork**)를 누릅니다.
3. Repository name은 `gym-metaverse` 그대로 두고, **Public**을 선택한 뒤 만듭니다.

**2. 학교 이름 바꾸기**
1. 내 사본에서 `js/config.js` 파일을 열고 오른쪽 위 ✏️(연필)을 누릅니다.
2. `schoolName: '갱갱중학교'` 의 학교 이름을 바꿉니다.
3. 오른쪽 위 **Commit changes** → 다시 **Commit changes** 를 누르면 저장됩니다.

**3. 사이트 켜기**
1. 내 사본의 **Settings → Pages** 로 갑니다.
2. Branch를 `main`, 폴더를 `/ (root)` 로 고르고 **Save** 를 누릅니다.
3. 1~2분 뒤 `https://내아이디.github.io/gym-metaverse/` 로 접속합니다.

여기까지 하면 **혼자 하기**로 모든 기구를 쓸 수 있습니다.

**4. (선택) 여러 명 동시 접속 켜기** — 내 Firebase가 필요합니다 (무료)
1. https://console.firebase.google.com 에서 **프로젝트 만들기** (Google 애널리틱스는 꺼도 됨).
2. 왼쪽 메뉴 **빌드 → Authentication → 시작하기 → 로그인 방법 → 익명** 을 사용 설정.
3. **빌드 → Realtime Database → 데이터베이스 만들기** (위치: 싱가포르 asia-southeast1 추천, '잠금 모드'로 시작).
4. Realtime Database의 **규칙** 탭에 이 저장소의 `database.rules.json` 내용을 그대로 붙여 넣고 **게시**.
5. **프로젝트 설정(⚙️) → 일반 → 내 앱 → 웹(</>)** 으로 앱을 등록하면 나오는 `firebaseConfig` 값을 복사합니다.
6. 내 사본의 `js/config.js` 에서
   - `firebase: { ... }` 안의 값을 방금 복사한 내 값으로 바꾸고,
   - `firebaseSite: 'kimkiyeop1-ux.github.io'` 를 **내 주소**(예: `'내아이디.github.io'`)로 바꿉니다.
7. `index.html` 의 `VERSION` 값을 하나 올리면(예: `'5-5'` → `'5-6'`) 휴대폰에도 바로 반영됩니다.

> 원래 사이트의 Firebase는 원래 사이트 주소에서만 동작하도록 막혀 있습니다. 사본에서 `firebase` 값을 바꾸지 않으면 여러 명 접속은 꺼지고 혼자 하기만 됩니다.

## 설정
학교명 등은 `js/config.js` 한 곳에서 바꿉니다. 화면 제목, 무대 현수막, 홈 화면 앱 이름에 모두 반영됩니다.
- `schoolName`: 학교 이름
- `firebase`, `firebaseSite`: 여러 명 접속 서버와 그 서버를 쓸 사이트 주소 (사본은 위 4번 참고)
- `equipment.ballScale`: 공 크기 비율 (1 = 실제 규격)
- `equipment.volleyNetHeight`: 배구 네트 높이

## 여러 명 동시 접속
- 입장할 때 **닉네임**(2~8글자)과 **방 코드**(예: `1-3`, 비우면 `공용`)를 넣습니다. 같은 방 코드끼리만 만납니다. 방마다 최대 30명.
- 공·기구는 함께 씁니다. 마지막으로 만진(잡기·차기·밀기) 사람의 기기가 계산해서 다른 사람에게 보냅니다.
- 친구끼리 플래그를 뽑을 수 있고, 골은 모두에게 "○○ 골!"로 알려집니다. 연습 친구는 방장(가장 먼저 들어온 사람) 화면에서 움직입니다.
- 서버: Firebase 실시간 데이터베이스 + 익명 로그인. `js/config.js` 의 `firebase` 에 설정값을 넣고, `database.rules.json` 내용을 Firebase 콘솔의 Realtime Database → 규칙에 붙여 넣습니다.
- 설정이 없으면 혼자 하기만 됩니다. 개발 중에는 주소 뒤에 `?net=local` 을 붙이면 같은 브라우저의 여러 탭끼리 테스트할 수 있습니다.
- **패스 도우미**: 공을 들고 친구 쪽을 보면 친구 머리 위에 노란 화살표·발밑에 원이 생기고, Q가 **패스**, F가 **차서 패스**로 바뀝니다. 누르면 공이 친구에게 알아서 날아가고(움직이는 친구는 앞을 노림), 받는 친구는 **자동으로 잡습니다**(발 패스는 발 앞에 멈춤). 자동으로 잡는 건 나에게 온 패스뿐입니다.
- **패스 해줘**: 손이 비었을 때 R을 누르면 3초 동안 손을 들고 머리 위에 "패스!"가 뜹니다. 손 든 친구는 패스 대상으로 더 쉽게 잡힙니다.
- 채팅은 없습니다. 닉네임은 기본적인 나쁜 말을 막습니다.

## 종목별 경기 (농구·풋살·배구·배드민턴·츄크볼)
- 자유 체육관 +z 벽 쪽의 **색깔 발판**(🏀 농구 · ⚽ 풋살 · 🏐 배구 · 🏸 배드민턴 · 🥅 츄크볼)에 서서 E(모바일은 버튼)를 누르면 그 종목 **경기장**으로 이동합니다. 간판에 지금 경기장에 있는 인원이 표시됩니다.
- 경기장은 같은 방 코드 + 같은 종목끼리만 모이는 **따로 된 공간**입니다 (Firebase 방 이름 `방코드~bb` 등). 다른 종목·자유 체육관 사람은 보이지 않습니다.
- 들어오면 사람이 적은 팀(🔴 빨강/🔵 파랑 조끼)에 들어가고, 2명 이상이면 **▶ 경기 시작** → 3·2·1 → **5분 경기**. 시작할 때 입장 순서대로 팀을 번갈아 다시 나눕니다.
- 점수 자동 판정: 농구 골 2점, 3점 라인(림에서 6.75m, 코너는 사이드라인 쪽 |z|≥6.6) 밖에서 쏜 슛은 3점(빨강은 무대 반대편 골대), 풋살 골 1점(경기장에 골대 등장), 배구·배드민턴은 공이 상대 코트에 떨어지면 1점(코트 밖이면 마지막에 친 팀 실점), 득점 뒤 공은 자동으로 다시 놓임.
- 점수·시간은 방장(먼저 들어온 사람)이 정해 모두에게 알립니다. 🚪 나가기로 자유 체육관에 돌아옵니다.
- 자유 체육관에서는 배구·배드민턴 네트를 치웠습니다(그 종목 경기장에만 놓임). 배드민턴 경기장에서는 모두 라켓을 들고, 셔틀콕이 닿으면 F 하이클리어(높고 깊게) · Q 드롭(네트 앞) · R 헤어핀(네트 앞에서 낮은 셔틀콕을 살짝) · E 스매시(높은 셔틀콕을 점프해 내리꽂기). 팀과 상관없이 바라보는 방향 쪽 코트로(좌우도 바라보는 방향), 네트를 넘을 높이로 자동 계산. 셔틀콕은 떨어진 자리에 멈춤. 서브도 같은 버튼으로.
- 농구: 멀리서 쏠수록 슛 게이지 초록 구간이 좁아짐(골밑 → 중거리 → 3점 → 장거리). 3점 라인 밖이면 버튼이 '3점 슛'. 수비는 상대 공 근처에서 Q 블락(점프해 손에 닿은 슛을 쳐 냄). 경기 중 패스는 같은 팀에게만
- 풋살: 손은 쓰지 않음. 공에 다가가면 자동 드리블(발 앞에 붙어 따라옴), F 차서 패스(같은 팀)/차기, 골문 쪽을 보면 Q 슛(꾹 눌러 힘, 초록 구간이면 바라본 쪽 구석으로 낮고 강하게, 약하면 힘없는 슛, 세면 골대 위·옆으로). 상대 드리블 공에 바짝 붙으면 뺏기(주인이 바뀐 뒤 1.5초 보호)
- 츄크볼: 양쪽 끝 골대(x = ±12, 고정), 골대 앞 반지름 3m 금지 구역(바닥 반원). 두 팀 모두 어느 골대든 슛(골대 쪽을 보면 Q 슛, 그물 가운데로 자동 조준, 금지 구역 안에서는 슛 불가). 그물에 맞고 튄 공이 코트 안(금지 구역 밖) 바닥에 떨어지면 공격 팀 +1, 상대 팀이 잡으면 수비 성공(점수 없음), 코트 밖·금지 구역에 떨어지거나 공격 팀이 다시 잡으면 수비 팀 +1. 공은 피구공. (3번 패스·3걸음 규칙은 없음)
- 방 코드는 최대 10자입니다 (경기장 방 이름이 12자를 넘지 않게).

## 조작
- PC: WASD/방향키 이동, 스페이스 점프, 마우스를 움직이면 시점(입장하면 바로 켜짐, Esc 로 커서 꺼내기, 화면 클릭으로 다시 켜기), 휠 확대·축소
- 모바일: 왼쪽 조이스틱 이동, 오른쪽 드래그 시점, 두 손가락 확대·축소, 점프 버튼
- 기구 동작 (PC 키 / 모바일은 기구 가까이 가면 버튼이 나타남)
  - E: 잡기·놓기·플래그 착용·플래그 뽑기
  - Q: 꾹 눌러 힘 모아 던지기 (농구공을 들고 골대를 보면 '슛', 초록 구간에서 떼면 골)
  - F: 차기·라켓 치기·스파이크·킨볼 띄우기
  - R: 토스 (배구공·빅발리볼), 여러 명일 때 손이 비면 '패스 해줘'
  - 스파이크: 떠 있는 배구공 근처에서 F → 자동으로 점프해 손이 닿는 순간 때림 (팀과 상관없이 바라보는 방향으로, 네트 쪽이면 네트를 넘길 높이 자동)
  - 블로킹: 배구 경기장 네트 앞에서 Q → 두 팔을 들고 점프, 날아온 공을 상대 코트로 떨어뜨림
  - 친구 쪽을 보고 있으면 Q '패스'·F '차서 패스' (자동 조준)
  - 줄넘기: 들고 F(또는 점프)로 시작, 줄이 발밑에 올 때 맞춰 뛰기
  - 훌라후프: F 돌리기(계속 눌러 힘 주기), Q 바닥에 굴리기
  - 추크볼 골대·배드민턴 지주: 몸으로 밀어서 이동
  - 🧺 정리: 모든 공과 기구를 제자리로
  - 👕 꾸미기: 머리 모양(4)·머리색(6)·신발색(6)·등번호(0~99). 이 기기에 저장되고 친구 화면에도 보임
  - 잡기: 1.1m 안에서 바라보는 쪽의 물건을 먼저 잡고, 잡힐 물건 밑에 흰 원이 표시됨

## 용기구 보관 구역
모든 공·작은 용기구는 −z 벽 쪽 **용기구 보관 구역**의 이름표가 붙은 칸에 놓여 있고, 🧺 정리 버튼을 누르면 각자 칸으로 돌아갑니다.
칸 순서·위치·이름은 `js/storageArea.js`의 `STORAGE_SLOTS`에서 바꿉니다.

## 저장 규칙
localStorage 키는 모두 `gym_`으로 시작하며(`js/storage.js`), 다른 키는 읽거나 지우지 않습니다.
사용하는 키: `gym_help_seen`, `gym_camera_distance`, `gym_sound`, `gym_jumprope_best`, `gym_hulahoop_best`, `gym_nickname`, `gym_room`, `gym_look`(꾸미기), `gym_pixel_ratio`(자동 화질)

## 화면 다듬기
- 사람·공 밑 둥근 그림자(진짜 그림자 계산 없이 흐린 원), 착지·세게 떨어진 공의 먼지 효과

## 업데이트 배포 시
`index.html`의 `VERSION` 값을 바꾸면 휴대폰 브라우저와 홈 화면 앱이 예전 파일(캐시) 대신 새 파일을 받습니다.
(서비스 워커 `sw.js` 가 새 버전을 설치하고 예전 저장본을 지웁니다. 저장본 이름은 `gym-metaverse-` 로 시작하며 다른 이름의 저장본은 건드리지 않습니다.)
`js/`에 새 파일을 추가하면 같은 곳의 `MODULES` 목록에도 이름을 넣어야 합니다.
