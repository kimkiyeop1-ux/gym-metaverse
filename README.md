# 가상 체육관 (gym-metaverse)

학교 체육관을 3D로 재현한 웹 공간입니다. 기획은 [PLAN.md](PLAN.md)를 참고하세요.

## 실행
빌드 과정이 없습니다. 라이브러리(Three.js, cannon-es)는 `js/vendor/`에 포함되어 있습니다.

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속 (주소 뒤에 ?fps 를 붙이면 FPS 표시)
```

## 설정
학교명 등은 `js/config.js` 한 곳에서 바꿉니다.

## 조작
- PC: WASD/방향키 이동, 스페이스 점프, 마우스 드래그 시점, 휠 확대·축소
- 모바일: 왼쪽 조이스틱 이동, 오른쪽 드래그 시점, 두 손가락 확대·축소, 점프 버튼
- 기구 동작 (PC 키 / 모바일은 기구 가까이 가면 버튼이 나타남)
  - E: 잡기·놓기·플래그 착용·플래그 뽑기
  - Q: 꾹 눌러 힘 모아 던지기 (농구공을 들고 골대를 보면 '슛', 초록 구간에서 떼면 골)
  - F: 차기·라켓 치기·스파이크·킨볼 띄우기
  - R: 토스 (배구공·빅발리볼)
  - 줄넘기: 들고 F(또는 점프)로 시작, 줄이 발밑에 올 때 맞춰 뛰기
  - 훌라후프: F 돌리기(계속 눌러 힘 주기), Q 바닥에 굴리기
  - 추크볼 골대·배드민턴 지주·배구 이동식 지주: 몸으로 밀어서 이동
  - 배구 이동식 지주 2개 사이가 5~11m 이면 네트가 자동으로 걸림
  - 🧺 정리: 모든 공과 기구를 제자리로

## 저장 규칙
localStorage 키는 모두 `gym_`으로 시작하며(`js/storage.js`), 다른 키는 읽거나 지우지 않습니다.

## 업데이트 배포 시
`index.html`의 `VERSION` 값을 바꾸면 휴대폰 브라우저가 예전 파일(캐시) 대신 새 파일을 받습니다.
`js/`에 새 파일을 추가하면 같은 곳의 `MODULES` 목록에도 이름을 넣어야 합니다.
